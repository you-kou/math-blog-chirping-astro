假设有两个函数 $f(u)$ 和 $g(x)$：

- **内层函数**：$u = g(x)$
- **外层函数**：$y = f(u)$

把 $g(x)$ 代入到 $f(u)$ 中，就得到了复合函数，记作：

$$y = f(g(x)) \quad \text{或} \quad (f \circ g)(x)$$

## 经典示例

为了清楚说明“组合”与“拆解”的过程：

| **复合函数 y=f(g(x))** | **外层函数 y=f(u)** | **内层函数 u=g(x)** | **计算示例（当 x=2 时）**    |
| ---------------------- | ------------------- | ------------------- | ---------------------------- |
| **$y = (2x + 1)^2$**   | $y = u^2$           | $u = 2x + 1$        | $u = 5 \implies y = 25$      |
| **$y = \sin(3x)$**     | $y = \sin(u)$       | $u = 3x$            | $u = 6 \implies y = \sin(6)$ |
| **$y = e^{-x^2}$**     | $y = e^u$           | $u = -x^2$          | $u = -4 \implies y = e^{-4}$ |

## 两大核心要素

### 定义域的限制

复合函数 $f(g(x))$ 要有意义，**内层函数 $g(x)$ 的值域必须包含在外层函数 $f(u)$ 的定义域之内**（或两者必须有交集）。

- _示例_：设 $f(u) = \sqrt{u}$（要求 $u \ge 0$），$g(x) = -x^2 - 1$（值域为 $(-\infty, -1]$）。因为 $g(x)$ 永远为负数，无法传入 $f(u)$，所以 $f(g(x)) = \sqrt{-x^2 - 1}$ 在实数范围内无意义。

### 求导法则

对复合函数求导时，需要像剥洋葱一样**从外向内逐层求导**：

$$\frac{\mathrm{d}y}{\mathrm{d}x} = \frac{\mathrm{d}y}{\mathrm{d}u} \cdot \frac{\mathrm{d}u}{\mathrm{d}x} = f'(g(x)) \cdot g'(x)$$

- **口诀**：_外层求导，内层不变；乘以内层求导。_
- **练习**：求 $y = \ln(x^2 + 1)$ 的导数：
  1. 外层求导：$\frac{1}{u} = \frac{1}{x^2 + 1}$
  2. 内层求导：$(x^2 + 1)' = 2x$
  3. 最终结果：$y' = \frac{2x}{x^2 + 1}$

## 对应法则：复合函数解析式求解

求解复合函数解析式的核心在于**理解对应法则的作用对象**。根据已知条件的不同，主要分为以下两大经典类型：

### 类型一：知内求外（已知内层规则与复合结果，求外层规则）

> **解题核心：** 将内层整体 $g(x)$ 视作一个新变量，剥离出外层法则 $f$。最常用**换元法**与**凑配法**。

#### 方法 1：换元法（通用性强）

设内层整体 $g(x) = t$，反解出 $x = h(t)$ 代入表达式，最后将 $t$ 统一替换回目标变量。

> ⚠️ **避坑要点：** 换元必换范围！必须先求出新变量 $t$ 的取值范围（即 $g(x)$ 的值域），这直接决定了 $f(x)$ 的定义域。

- **例题：** 已知 $f(2x + 1) = 4x^2 + 6x + 5$，求 $f(x)$。

- **解析步骤：**

  1. **设元换范围：** 令 $t = 2x + 1$。因为 $x \in \mathbb{R}$，所以 $t \in \mathbb{R}$。

  2. **反解代入：** 由 $t = 2x + 1$ 得 $x = \frac{t - 1}{2}$，代入原式：

     $$f(t) = 4\left(\frac{t - 1}{2}\right)^2 + 6\left(\frac{t - 1}{2}\right) + 5$$

  3. **化简整理：**

     $$f(t) = (t^2 - 2t + 1) + (3t - 3) + 5 = t^2 + t + 3$$

  4. **得出结论：** $f(x) = x^2 + x + 3 \quad (x \in \mathbb{R})$。

#### 方法 2：凑配法（适合结构明显的题目）

不显式设新变量，而是直接将等式右侧改写为包含“内层整体 $g(x)$”的结构，再作整体替换。

- **例题：** 已知 $f\left(x + \frac{1}{x}\right) = x^2 + \frac{1}{x^2}$，求 $f(x)$。

- **解析步骤：**

  1. **变形凑配：** 利用乘法公式拼凑内层结构：

     $$f\left(x + \frac{1}{x}\right) = \left(x + \frac{1}{x}\right)^2 - 2$$

  2. **限定范围：** 根据均值不等式，当 $x \neq 0$ 时，$\left\vert{}x + \frac{1}{x}\right\vert{} \ge 2$，即整体取值范围为 $(-\infty, -2] \cup [2, +\infty)$。

  3. **整体替换：** $f(x) = x^2 - 2 \quad (\vert{}x\vert{} \ge 2)$。

### 类型二：知外求内（已知外层规则与复合结果，求内层规则）

> **解题核心：** 将未知内层 $g(x)$ 直接作为整体套用外层法则 $f$，转化为求解关于 $g(x)$ 的方程。

#### 方法 1：方程法（代数直接法）

利用已知法则 $f$ 的运算逻辑，将 $g(x)$ 代入构建代数方程直接求解。

- **例题：** 已知外层函数 $f(x) = 3x - 2$，且 $f(g(x)) = 6x^2 + 3x + 1$，求 $g(x)$。
- **解析步骤：**
  1. **按规则作用：** 根据 $f$ 的定义（对输入量做“3倍减2”操作），有 $f(g(x)) = 3g(x) - 2$。
  2. **建立方程：** $3g(x) - 2 = 6x^2 + 3x + 1$。
  3. **求解目标：** $3g(x) = 6x^2 + 3x + 3 \implies g(x) = 2x^2 + x + 1$。

#### 方法 2：待定系数法（已知函数类型时使用）

若题目明确告知了 $g(x)$ 的函数类型（如一次函数、二次函数等），可先设出含待定系数的标准式，再对比等式两边的系数。

- **例题：** 已知 $f(x) = x^2 + 1$，$g(x)$ 为一次函数，且 $f(g(x)) = 4x^2 - 12x + 10$，求 $g(x)$。

- **解析步骤：**

  1. **设待定系数：** 设 $g(x) = ax + b \quad (a \neq 0)$。

  2. **展开复合式：**

     $$f(g(x)) = (ax + b)^2 + 1 = a^2x^2 + 2abx + (b^2 + 1)$$

  3. **对照系数列方程组：**

     $$\begin{cases} a^2 = 4 \\ 2ab = -12 \\ b^2 + 1 = 10 \end{cases}$$

  4. **求解并校验：** 解得 $\begin{cases} a = 2 \\ b = -3 \end{cases}$ 或 $\begin{cases} a = -2 \\ b = 3 \end{cases}$。

  5. **得出结论：** $g(x) = 2x - 3$ 或 $g(x) = -2x + 3$。
