在数学中，**正数与负数的引入**完成了数的概念的第一次关键扩张，而**有理数及其运算**则是整个代数学习的基石。

## 正数、负数与零

为了表示实际生活中**具有相反意义的量**（如收入与支出、上升与下降、零上与零下），数学中引入了负数。

### 定义

- **正数（Positive Numbers）**：大于 $0$ 的数，如 $3, 0.5, \frac{2}{3}$。正号“$+$”通常省略不写。
- **负数（Negative Numbers）**：在正数前面加上负号“$-$”的数，如 $-3, -0.5, -\frac{2}{3}$。**负号绝对不能省略**。
- **数字 $0$**：**$0$ 既不是正数，也不是负数**，它是正数与负数的分界点（基准）。

### 具有相反意义的量

表示相反意义的量时，需先指定某一状态为正，则其对立状态自然为负：

- **收支盈亏**：收入 $+500$ 元，支出记作 $-200$ 元。
- **位置方向**：向东走 $+10$ 米，向西走记作 $-10$ 米。
- **温度/高度**：零上 $15^\circ\text{C}$ 记作 $+15^\circ\text{C}$；海拔低于海平面 $100$ 米记作 $-100$ 米。

## 什么是有理数？

### 有理数的定义

**凡是能写成分数形式 $\frac{p}{q}$（其中 $p, q$ 均为整数，且 $q \neq 0$）的数，都叫做有理数。**

- 有限小数（如 $0.25 = \frac{1}{4}$）和无限循环小数（如 $0.333\dots = \frac{1}{3}$）都能化为分数，因此都是有理数。
- 无限不循环小数（如 $\pi$ 或 $0.1010010001\dots$）不能写成分数形式，**不是**有理数（属于无理数）。

### 有理数的两种分类方式

有理数有两种常见的分类方式：

1. #### 按“定义（形态）”分类
   - **整数**
     - 正整数：如 $1, 2, 3$
     - $0$（既不是正数也不是负数）
     - 负整数：如 $-1, -2, -3$
   - **分数**
     - 正分数：如 $\frac{1}{2}, 3.5, 4\frac{1}{3}$
     - 负分数：如 $-\frac{2}{3}, -0.75$

2. #### 按“性质符号”分类
   - **正有理数**（正整数、正分数）
   - **零（$0$）**
   - **负有理数**（负整数、负分数）

### 数轴（Number Line）

- **三要素**：**原点**、**正方向**（通常向右）、**单位长度**。
- **基本性质**：任何一个有理数都可以用数轴上的一个点来表示；数轴上**右边的点表示的数总比左边的点大**。

### 相反数（Opposite Numbers）

- **定义**：只有**符号不同**的两个数叫做互为相反数（如 $5$ 与 $-5$）。
- **几何意义**：在数轴上，互为相反数的两个点位于原点两侧，且到原点的**距离相等**。
- **代数性质**：
  - $a$ 的相反数是 $-a$；$0$ 的相反数是 $0$。
  - 若 $a, b$ 互为相反数，则 $a + b = 0$。

### 绝对值（Absolute Value）

- **几何定义**：数轴上表示数 $a$ 的点到原点的**距离**，记作 $\vert{}a\vert{}$。

- **代数定义**：

  $$\vert{}a\vert{} = \begin{cases} a & (a > 0) \\ 0 & (a = 0) \\ -a & (a < 0) \end{cases}$$

- **核心性质（非负性）**：任何数的绝对值都大于或等于 $0$，即 $\vert{}a\vert{} \ge 0$。

## 有理数的四则运算与乘方

有理数运算的核心逻辑是：**“先定符号，再算数值”**。

| **运算** | **法则要点**                                                                                                                         | **经典示例**                                      |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------- |
| **加法** | ① **同号相加**：取相同符号，绝对值相加。 ② **异号相加**：取绝对值较大者的符号，用大绝对值减小绝对值。 ③ 互为相反数的两数相加得 $0$。 | $(-3) + (-5) = -8$ $(-8) + 5 = -3$ $(-5) + 5 = 0$ |
| **减法** | 减去一个数，等于加上这个数的相反数：$a - b = a + (-b)$                                                                               | $3 - (-5) = 3 + 5 = 8$                            |
| **乘法** | **同号得正，异号得负，绝对值相乘**；任何数与 $0$ 相乘均得 $0$。                                                                      | $(-4) \times (-3) = 12$ $(-4) \times 3 = -12$     |
| **除法** | 除以一个不等于 $0$ 的数，等于乘以这个数的倒数：$a \div b = a \times \frac{1}{b}$                                                     | $(-12) \div (-3) = 12 \times \frac{1}{3} = 4$     |
| **乘方** | $a^n$ 表示 $n$ 个 $a$ 相乘： ① 正数的任何次幂都是正数； ② **负数的奇次幂是负数，负数的偶次幂是正数**。                               | $(-2)^3 = -8$ $(-2)^4 = 16$                       |

> **混合运算顺序**：先算乘方，再算乘除，最后算加减；如果有括号，先算小括号，再算中括号，最后算大括号。

## 易错点与陷阱总结

1. **“$0$”的特殊性质**：
   - $0$ 是整数也是有理数，但**既不是正数也不是负数**。
   - $0$ 的绝对值是 $0$，相反数是 $0$，但 **$0$ 没有倒数**（不能作为除数）。
2. **字母 $-a$ 不一定是负数**：
   - 当 $a > 0$ 时，$-a$ 是负数；
   - 当 $a = 0$ 时，$-a = 0$；
   - 当 $a < 0$ 时（例如 $a = -2$），$-a = -(-2) = 2$ 是**正数**。
3. **乘方中的括号陷阱**（区分底数）：
   - $(-3)^2$ 表示 $-3$ 的平方，结果为 $9$；
   - $-3^2$ 表示 $3$ 的平方的相反数，即 $-(3 \times 3)$，结果为 $-9$。
4. **倒数与相反数的区别**：
   - **倒数**：乘积为 $1$ 的两数互为倒数（符号保持一致，如 $-\frac{2}{3}$ 的倒数是 $-\frac{3}{2}$）。
   - **相反数**：和为 $0$ 的两数互为相反数（符号相反，如 $-\frac{2}{3}$ 的相反数是 $\frac{2}{3}$）。
