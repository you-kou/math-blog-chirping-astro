在微积分中，函数的间断点（Point of Discontinuity）指的是函数图像在该点处出现“断裂”、“漏洞”或“无法连续画出”的点。

简单来说，如果函数 $f(x)$ 在点 $x_0$ 满足以下**任意一条**，那么 $x_0$ 就是一个间断点：

1. $f(x)$ 在 $x_0$ 处没有定义（比如分母为 0）。
2. $\lim_{x \to x_0} f(x)$ 不存在（左右极限不相等或趋于无穷）。
3. 极限存在且有定义，但 $\lim_{x \to x_0} f(x) \neq f(x_0)$（极限值不等于函数值）。

## 间断点的两大分类

数学上通常以左右极限是否存在（有限值）为依据，将间断点分为两大类：

### 第一类间断点

如果在点 $x_0$ 处，左极限 $\lim_{x \to x_0^-} f(x)$ 和右极限 $\lim_{x \to x_0^+} f(x)$ **都存在且为有限实数**，则称 $x_0$ 为第一类间断点。它又细分为两种：

#### 可去间断点（Removable Discontinuity）

- **特征**：左右极限相等（即极限存在），但该点**没有定义**或**极限值不等于函数值**。
- **表现**：图像上看起来只是多了一个“空心洞”。只要重新补上或修改 $f(x_0)$ 的定义，就能把这个洞“填平”，使函数恢复连续。
- **典型例子**：$f(x) = \frac{\sin x}{x}$ 在 $x = 0$ 处。左右极限都为 $1$，但 $x=0$ 无定义。

#### 跳跃间断点（Jump Discontinuity）

- **特征**：左右极限都存在，但**左右极限不相等**（即 $\lim_{x \to x_0^-} f(x) \neq \lim_{x \to x_0^+} f(x)$）。
- **表现**：图像在该点发生垂直“断层”或跳跃，左右两边的线对不上。
- **典型例子**：阶梯函数或分段函数，如符号函数 $f(x) = \text{sgn}(x)$ 在 $x = 0$ 处，左极限为 $-1$，右极限为 $1$。

### 第二类间断点

只要左极限或右极限**至少有一个不存在**（或者趋于无穷），该点就属于第二类间断点。常见类型有：

#### 无穷间断点（Infinite Discontinuity）

- **特征**：当 $x \to x_0$ 时，函数的左极限或右极限趋于 $\infty$ 或 $-\infty$。
- **表现**：函数图像在该点附近形成**垂直渐近线**，无限向上或向下延伸。
- **典型例子**：$f(x) = \frac{1}{x}$ 在 $x = 0$ 处，$x \to 0^+$ 时趋于 $+\infty$，$x \to 0^-$ 时趋于 $-\infty$。

#### 震荡间断点（Oscillating Discontinuity）

- **特征**：当 $x \to x_0$ 时，函数值在两个固定数之间进行无限次密集震荡，导致极限根本无法确定。
- **典型例子**：$f(x) = \sin\left(\frac{1}{x}\right)$ 在 $x = 0$ 处，越靠近 $0$，震荡越剧烈。

## 快速判断流程总结

在解题或分析函数时，判断间断点的步骤非常直观：

| **步骤**   | **检查项**                                      | **结论**            |
| ---------- | ----------------------------------------------- | ------------------- |
| **Step 1** | 计算左极限 $L_{left}$ 和右极限 $L_{right}$      | —                   |
| **Step 2** | 若 $L_{left}$ 和 $L_{right}$ 都存在（有限数）： | **第一类间断点**    |
|            | ↳ 若 $L_{left} = L_{right} \neq f(x_0)$         | 属于 **可去间断点** |
|            | ↳ 若 $L_{left} \neq L_{right}$                  | 属于 **跳跃间断点** |
| **Step 3** | 若 $L_{left}$ 或 $L_{right}$ 至少有一个不存在： | **第二类间断点**    |
|            | ↳ 若趋于 $\pm\infty$                            | 属于 **无穷间断点** |
|            | ↳ 若无限震荡                                    | 属于 **震荡间断点** |
